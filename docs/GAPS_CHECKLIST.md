# Gameplay gap checklist

This records implemented browser behavior and the work still needed. Native geometry, textures, animations and sound samples are used; gameplay controllers are authored approximations unless documented otherwise. The target is original PC 1.0 (user decision, September 17, 2026). Implemented, source-backed and reference-matched are separate states. The legacy implementation column below includes historical claims and is not proof of one-to-one compatibility. See [the current fidelity audit](FIDELITY_AUDIT.md).
